# 信息收集与可信度

## 来源优先级（高 → 低）

1. 一手：亲自试用、拆解、用户访谈、公开财报/招股书、官方定价页
2. 二手高可信：权威评测、第三方数据报告（IDC/Gartner 等）、专利
3. 二手中可信：媒体深度报道、官方博客
4. 二手低可信：用户评论、招聘 JD、营销软文、论坛

## 可信度标注规范

每条关键事实标注：

- **来源**：哪来的
- **时间**：何时（信息会过期，尤其定价和功能）
- **可信度**：高 / 中 / 低 + 一句话理由

## 事实 vs 推断 vs 观点

- **事实**：可验证（"竞品 A 定价 $29/月"）
- **推断**：由事实推导（"竞品 A 定价 $29/月 → 瞄准中小企业"）
- **观点**：主观判断（"竞品 A 体验差"）

输出时必须区分，不能把推断或观点写成事实。

## 反确认偏误清单

- 主动找至少一条"对我方不利"的证据
- 主动找"竞品做得比我好"的点
- 对"证明我方更强"的证据提高验证门槛
- 避免只引用支持自己立场的来源
- 信息矛盾时如实呈现，不做取舍

## 信息不足处理

- 明确写"未知/待验证"，不脑补
- 可给出"需要用户补充的材料清单"
