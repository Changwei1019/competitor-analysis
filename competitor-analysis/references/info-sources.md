# 信息收集与可信度

## 检索渠道与工具（中文优先）

- 检索中文公司/产品优先用 360 搜索（so.com）或搜狗（sogou.com），结果稳定。
- 避开：Bing 对中文多字词查询编码不稳定（易退回单字或英文结果）；百度对脚本访问有反爬验证（返回“网络不给力/安全验证”）。
- 用 `curl --get --data-urlencode "q=关键词"` 正确编码中文查询词，避免手工拼 URL 出错。
- 抓取网页正文可用 Jina Reader 代理：`https://r.jina.ai/<目标URL>`，返回 Markdown 便于提取。
- 从搜索结果页提取标题/链接时优先抓 `<h3>` 标题；结果页里混有大量站点自身资源 URL，需过滤（排除 so.com/360 等自身域名）。

## 来源优先级（高 → 低）

1. 一手：亲自试用、拆解、用户访谈、公开财报/招股书、官方定价页
2. 二手高可信：权威评测、第三方数据报告（IDC/Gartner 等）、专利
3. 二手中可信：媒体深度报道、官方博客
4. 二手低可信：用户评论、招聘 JD、营销软文、论坛

## 可信度标注规范

每条关键事实标注：

- **来源**：哪来的
- **时间**：何时（信息会过期，尤其定价和功能）
- **可信度**：高 / 中 / 低 + 一句话理由

## 事实 vs 推断 vs 观点

- **事实**：可验证（"竞品 A 定价 $29/月"）
- **推断**：由事实推导（"竞品 A 定价 $29/月 → 瞄准中小企业"）
- **观点**：主观判断（"竞品 A 体验差"）

输出时必须区分，不能把推断或观点写成事实。

## 反确认偏误清单

- 主动找至少一条"对我方不利"的证据
- 主动找"竞品做得比我好"的点
- 对"证明我方更强"的证据提高验证门槛
- 避免只引用支持自己立场的来源
- 信息矛盾时如实呈现，不做取舍

## 信息不足处理

- 明确写"未知/待验证"，不脑补
- 可给出"需要用户补充的材料清单"
