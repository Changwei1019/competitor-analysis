# 竞品分析框架库

每个框架标注适用目的、怎么用、什么时候别用。

## 1. 功能对比矩阵（Feature Matrix）

适用：功能对标、立项、差距扫描。

- 功能维度按"用户价值"分组，不按产品菜单分组
- 每个功能标各方支持程度：支持 / 部分支持 / 不支持 / 未知
- 关键不是"有没有"，而是"做到什么程度、对用户真实价值如何"
- 输出：功能缺口、功能冗余、差异化功能

## 2. SWOT（我方 vs 主要竞品）

适用：战略定位、进入决策。

- S/W 针对我方内部，O/T 针对外部环境
- 禁止空洞词（如"品牌优势"），必须写具体、可验证的论据
- 优劣势是"相对竞品"而言，不是孤立自评

## 3. 价值曲线（Value Curve / ERRC）

适用：定位、差异化、蓝海机会。

- 横轴：竞争要素（价格、功能丰富度、易用性、服务、品牌、生态等）
- 纵轴：相对水平（1-10 或 低/中/高）
- 分别画我方与竞品曲线，找两类信号：
  - 我方过度投入但用户不在意 → Eliminate（消除）/ Reduce（降低）
  - 用户在意但竞争空白 → Raise（提升）/ Create（创造）

## 4. 商业模式与定价分析

适用：定价、市场进入、盈利评估。

- 拆解定价模式：订阅 / 买断 / 免费增值 / 交易抽成
- 对比单用户经济：客单价、LTV、获客成本、毛利
- 找价格空白带、捆绑/拆分机会

## 5. 用户口碑与信号

适用：需求洞察、声誉、竞品弱点。

- 渠道：应用商店评论、社区、社媒、客服反馈、招聘 JD
- 分析高频负向词（用户最抱怨什么）、高频正向词（最夸什么）、流失原因
- 注意幸存者偏差与情绪偏差，多条交叉验证再下结论

## 6. 技术与护城河

适用：竞争壁垒、防御、技术路线。

- 维度：专利 / 技术栈 / 数据积累 / 网络效应 / 规模效应 / 生态锁定
- 判断壁垒是"真壁垒"还是"可复制"，并标注时间窗
